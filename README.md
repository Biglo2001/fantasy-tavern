# The Lantern & Ladle prototype

A small, touch-friendly browser prototype for exploring the tavern serving loop. It uses plain HTML, CSS, and JavaScript, with no build step, game engine install, or downloaded art/audio assets.

## Play

Open `index.html` in a modern browser on a desktop or phone. The layout adapts to narrow screens and supports touch input.

## Try the loop

1. Open for the evening.
2. Read the guest's order and choose three ingredients.
3. Perform each preparation step shown on the main button.
4. Serve the result and watch the guest react.
5. Continue through all three guests to see the shift summary.

The prototype includes a berry drink, a root vegetable stew, and a cocoa nightcap. Selecting the wrong ingredients is allowed and changes the reaction and reward.

## Current scope

This is a first-look prototype, not a production mobile game. Progress resets when the page reloads. The sound control is only a placeholder. Illustrations are made from CSS and emoji so there are no external art, font, or audio dependencies.
